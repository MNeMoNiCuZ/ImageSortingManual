    Keyboard shortcuts

    Skip — leave this image undecided and move on. It joins the Skipped group so you can come back to it later.
    ← / BackspacePrev — go back to the last image you skipped or passed over and put it back in the queue. It is the quick way to undo a single Skip; the Skipped card puts them all back at once. Nothing on disk changes.
    Ctrl+ZUndo — reverse the last file move and put the files back.
    Ctrl+SSave project
    Ctrl+OChoose image folder
    Ctrl+EEdit categories
    Ctrl+EnterApply the waiting changes (deferred mode)
    ScrollZoom in/out centered on cursor
    DragPan the image when zoomed in
    ?This list
    EscClose a dialog

    The Skip key is yours to set or clear in Settings → Sorting.

    Category hotkeys are whatever you assign — letters, digits, function keys, numpad keys and modifier combinations all work, and they take effect immediately.

    Carry on from last time?

    Your categories and hotkeys are saved automatically. You can turn that off in Settings.
